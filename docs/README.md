# GokturkOBS Website

Apple-inspired, white, navigation-free landing page built with plain HTML, CSS and JavaScript. No Tailwind, build tooling or dependencies.

## Preview
Open `index.html` in a browser or run `python3 -m http.server 8000 --directory docs` from the repository root.

## Publish via GitHub Pages
After merging this branch, open repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/docs**, then save.

The website will be available at `https://gokturksahis.github.io/GokturkOBS/` after Pages deployment.
